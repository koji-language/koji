# Standard Library

The **Koji Standard Library** provides a collection of built-in modules to help you handle common tasks. Click on a section to jump directly to its documentation.

## Modules

-   [`time`](standard-library/time.md)  
    Delay execution and measure elapsed time.

-   [`file`](standard-library/file.md)  
    Read from, write to and remove files, and list and create directories.

-   [`path`](standard-library/path.md)  
    Join paths and get their parts: parent directory, name and extension.

-   [`datetime`](standard-library/datetime.md)  
    Get the current date and time, format and parse date strings.

-   [`math`](standard-library/math.md)  
    Perform basic mathematical operations and access constants like `pi`.

-   [`task`](standard-library/task.md)  
    Run functions at the same time: groups of tasks, channels and shared values.

-   [`http`](standard-library/http.md)  
    Send HTTP requests such as GET, POST, PUT, and DELETE.

-   [`json`](standard-library/json.md)  
    Parse JSON strings and convert data to JSON format.

-   [`regex`](standard-library/regex.md)  
    Work with regular expressions to search, match, and replace patterns in strings.

-   [`system`](standard-library/system.md)  
    Read the command-line arguments and the environment, end the program with an exit code, run other programs, and know the operating system.
